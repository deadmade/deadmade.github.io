fangtype

built alone · Studienarbeit
what

A VS Code tool for Python type annotations. Designed, implemented and tested independently. Jedi and the project's own inference passes infer the types, and the editor shows them as hints. When the developer accepts one, the language server writes the annotation and mypy validates it; a rejected annotation is not written.

stack
  • Python
  • TypeScript
  • VS Code
  • LSP
  • pygls
  • Jedi
  • libcst
  • mypy

RustLogger

team build
what

A logging pipeline as a Docker Compose stack. Containers log to syslog, collectors forward the lines through nginx to an API that indexes them into a five-node Elasticsearch cluster. A simulated sensor source feeds a second index, and a terminal interface searches both through the API.

  • Actix
  • Elasticsearch
  • Kibana
  • nginx

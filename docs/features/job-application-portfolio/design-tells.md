## Consolidated tells (sources: fix)

- Purple/blue gradient, glow (S1 S2 S3 S4 S6): flat ground, one accent.
- Gradient headline text (S2): plain text.
- Inter/default type (S1 S2 S3 S4 S6): chosen face, heading/body contrast.
- Three-card rows, repeated cards (S1 S3 S4 S6): vary structure, use lists.
- Centred everything (S1 S3 S4 S6): left-align, asymmetry.
- Uniform radius/shadow (S1 S2 S4 S6): own radius, borders.
- Glass cards (S1 S3 S6): solid surfaces.
- Emoji/generic icons (S1 S3 S4): one set or none.
- Pill labels, category headings (S1 S4): concrete headings.
- "Trusted by", invented stats (S1 S6): real proof or omit.
- Triads, buzzwords (S1 S4 S5 S6): specific claims.
- Equal spacing, alternating bands (S1 S4): group related items.
- Stock imagery (S1 S4 S6): real screenshots or none.
- Text without decisions or friction (S5): one-detail rule.

## What marks an authored site

- Specific enough to be wrong for anyone else [S5]; a sentence only you could write [S1].
- Real material: screenshots, photo, named testimonial, numbers [S1][S3]; real content first [S6].
- Constraints: capped palette, named typeface, own tokens, a no-list [S1][S2][S3][S6].
- A point of view [S6]; admitted friction [S5].
- Visible layout decisions [S1][S3][S4].
